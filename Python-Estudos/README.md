
# Anotações - PYTHON

O PYTHON surgiu em 1989, tendo como premissa ser uma linguagem de alto nível, fácil e objetiva. 



## ATALHOS ÚTEIS, DICAS E TERMOS

**VS CODE**

**Acessar documentação de determinado termo:**

*CTRL + (Click no termo)*

**Limpar o terminal:**

*CTRL + L*

**Abrir modo interativo:**

No terminal, escreva *PYTHON*, ou chame o script que você deseja rodar com o comando *python -i (nome do arquivo script + .py)

**PYTHON**

**Dir():** Comando que retorna os métodos a serem utilizados com o dado em questão.

**EX:** *Dir(1) Retornará todos os métodos que podem ser utilizados com números inteiros.*

**Help():** Retorna um descritivo rápido do método solicitado. 

**EX:** *Help(int) Retorna um descritivo do tipo int e o que podemos fazer com ele.*

**Snake case:** Termo utilizado para descrever variáveis ou nomes com as palavras separadas por *underscore*.

**EX:** *Projeto_Python_Calculadora*

## ESTRUTURAS DE REPETIÇÃO

**Diferença entre FOR e WHILE**

O comando FOR é utilizado quando é necessário repetir a ação por um número conhecido de vezes. Já o WHILE é utilizado quando não se sabe ao certo quantas vezes a ação se repetirá.
