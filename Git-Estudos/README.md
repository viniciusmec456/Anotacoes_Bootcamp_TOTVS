
# ANOTAÇÕES AULAS GIT E GITHUB

## O que é um software de versionamento? 

Programa que garante que todos os envolvidos no projeto possam trabalhar de forma conjunta em arquivos independentes ao original, juntando-os com facilidade após isso, além de facilitar o armazenamento das diferentes versões, controle de histórico e etc.

**VCS Centralizado (CVCS)**

Softwares que salvam e controlam as versões em um único servidor.

**VCS Distribuido (DVCS)**

Softwares que salvam e controlam as versões em um único servidor, porém mantém uma cópia local para acesso offline e backup.

## Arquivo README.md e MARKDOWN

Esses arquivos fazem parte da documentação do projeto, e o MARKDOWN é uma linguagem simples derivada do HTML que gera um formato de texto puro que pode ser editado facilmente em editores de código, no navegador ou no próprio GITHUB.
