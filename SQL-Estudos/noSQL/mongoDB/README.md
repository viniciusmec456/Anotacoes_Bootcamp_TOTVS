# 📘 Mongo-DB

## instalação MongoDB (Atlas)

Acesse a página oficial do MONGO (ATLAS) e crie uma conta gratuita. A plataforma oferece um ambiente de estudos limitado sem custos. 

## Prática

O mongoDB trabalha com estrutura de documentos (JSON), onde os dados são estruturados de forma diferente se comparado ao banco de dado relacional. Todas as informações podem ficar armazenadas em um só arquivo e/ou tabela, com um formato aninhado. 

Outro ponto interessante é que o banco de dados não relacional não trabalha com a normalização de dados, mas sim com a desnormalização, já que as relações que exigem as normas não estão presentes aqui.
