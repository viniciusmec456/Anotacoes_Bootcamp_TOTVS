# 📘 Anotações no-SQL

Modelos de dados não relacionais tem se tornado muito populares atualmente devido ao aumento da quantidade de dados gerados pela humanidade na internet. Esses modelos, sem a popular relação entre tabelas, garantem uma escalabilidade muito maior, já que não lidam com atualizações de milhares de tabelas quando um valor muda ou é adicionado de imediato, mas sim com um atraso.  

| SQL | noSQL| 
|----------|----------|
| Modelo de dados fixo | Modelo de dados flexível  |
| Escalabilidade vertical (Com hardware)  | Escalabilidade horizontal|
| Transações ACID 100%  | Transações ACID ausentes total ou parcial|
| Linguagem de consulta SQL  | Cada SGBD tem a sua|


Desvantagens principais: 

Menos consistência de dados de imediato; 

Menor suporte a consultas complexas (Depende do Software gerenciador)
